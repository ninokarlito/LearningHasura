# 📌 Apa Itu etcd?

**etcd** adalah penyimpanan data terdistribusi yang bersifat **key-value store** dan digunakan sebagai pusat penyimpanan konfigurasi dalam sistem terdistribusi, terutama Kubernetes.

## 🔹 Fungsi utama etcd
1. **Menyimpan Konfigurasi Kubernetes** → Menyimpan status cluster, termasuk informasi tentang nodes, pods, dan konfigurasi jaringan.
2. **Menyediakan Konsistensi Data** → Menggunakan protokol *Raft* untuk memastikan semua node memiliki data yang sama.
3. **Memfasilitasi Service Discovery** → Aplikasi dapat menggunakan etcd untuk mendaftarkan dirinya dan menemukan layanan lain dalam cluster.
4. **Menjadi Sumber Kebenaran Tunggal (Single Source of Truth)** → Semua komponen Kubernetes bergantung pada etcd untuk mendapatkan informasi terbaru tentang cluster.

---

## 🔹 Cara Kerja etcd dalam Kubernetes
1. **API Server Kubernetes** mengakses etcd untuk membaca dan memperbarui status cluster.
2. **Controller Manager & Scheduler** menggunakan data dari etcd untuk mengatur workload.
3. **Setiap Node Kubernetes (kubelet)** mendapatkan informasi konfigurasi dan status cluster dari etcd.

> 📌 **Contoh:** Saat membuat Deployment baru, informasi ini akan disimpan di etcd. Scheduler membaca dari etcd untuk menentukan node terbaik untuk menjalankan pod.

---

## 🔹 Arsitektur etcd
**etcd** terdiri dari beberapa komponen utama:
- **Cluster Leader** → Node utama yang menangani semua permintaan tulis (write requests).
- **Followers** → Node lain yang mereplikasi data dari leader untuk memastikan redundansi dan ketersediaan.
- **Client** → Komponen Kubernetes seperti API Server yang berkomunikasi dengan etcd untuk mendapatkan data terbaru.
- **Snapshot Storage** → Tempat penyimpanan snapshot dari database untuk pemulihan saat terjadi kegagalan.

**Diagram Arsitektur etcd dalam Kubernetes:**

## 🔹 Instalasi etcd
Untuk menginstal etcd secara manual di Linux:
```sh
wget https://github.com/etcd-io/etcd/releases/download/v3.5.5/etcd-v3.5.5-linux-amd64.tar.gz

tar xvf etcd-v3.5.5-linux-amd64.tar.gz

cd etcd-v3.5.5-linux-amd64

sudo mv etcd /usr/local/bin/
sudo mv etcdctl /usr/local/bin/
```
Verifikasi instalasi:
```sh
etcd --version
```

---

## 🔹 Contoh Penggunaan etcd
### **1. Menyimpan Data ke etcd**
```sh
etcdctl put /config/database "mysql://user:pass@localhost/db"
```
### **2. Mengambil Data dari etcd**
```sh
etcdctl get /config/database
```
### **3. Menghapus Data di etcd**
```sh
etcdctl del /config/database
```

## 🔹 Keunggulan etcd
✅ **Highly Available** → Dapat berjalan dalam mode cluster untuk redundansi.  
✅ **Strongly Consistent** → Menggunakan *Raft Consensus Algorithm* untuk memastikan konsistensi data.  
✅ **Lightweight & Fast** → Didesain untuk performa tinggi dengan latensi rendah.  
✅ **Scalable** → Mampu menangani beban kerja dalam sistem besar seperti Kubernetes.

---

## 🔹 Kesimpulan
**etcd** adalah komponen kritis dalam Kubernetes yang berfungsi sebagai penyimpanan data terdistribusi dengan tingkat konsistensi tinggi. Tanpa **etcd**, Kubernetes tidak dapat berfungsi dengan baik karena semua status cluster disimpan di dalamnya.
