Kubernetes adalah sebuah platform yang digunakan untuk mengelola, menjadwalkan, dan mengatur beban kerja berbasis container dalam skala besar. Namun, definisi Kubernetes sering kali menjadi perdebatan karena ada banyak perspektif mengenai apakah Kubernetes adalah **platform, infrastruktur, atau aplikasi**. Daripada memperdebatkan definisi tersebut, lebih baik kita fokus pada **masalah yang diselesaikan oleh Kubernetes** dan bagaimana fitur-fitur yang dimilikinya membantu mencapai **kondisi Kubernetes produksi**—di mana workload atau aplikasi dapat berjalan dengan stabil dan siap menangani trafik pengguna secara nyata.

## Kubernetes dalam Ekosistem Open Source

Ketika kita berbicara tentang **Kubernetes**, kita sebenarnya berbicara tentang sebuah proyek open-source yang sangat luas. Jika kita melihat repositori di **GitHub**, kita akan menemukan:

- **Organisasi GitHub `kubernetes`**, yang memiliki sekitar **69 repositori** (pada saat tulisan ini dibuat).
- **Organisasi `kubernetes-sigs`**, yang memiliki lebih dari **107 proyek**.
- **Ekosistem CNCF (Cloud Native Computing Foundation)**, yang memiliki ratusan proyek terkait Kubernetes.

Namun, dalam konteks pembahasan ini, kita akan fokus pada **proyek inti Kubernetes**, yaitu yang terdapat dalam repositori [`kubernetes/kubernetes`](https://github.com/kubernetes/kubernetes) di GitHub.

## Apa yang Ada di Repositori `kubernetes/kubernetes`?

Repositori ini adalah inti dari Kubernetes dan berisi **komponen utama** yang biasanya ada di setiap kluster Kubernetes. Jika kita menjalankan kluster Kubernetes dengan komponen-komponen ini, maka kita mendapatkan fitur-fitur berikut:

1. **Menjadwalkan beban kerja pada banyak host**  
   Kubernetes dapat mendistribusikan container ke berbagai server (node) dan mengelolanya secara otomatis.

2. **Menyediakan API yang deklaratif dan dapat diperluas**  
   Kubernetes memiliki API yang memungkinkan pengguna untuk mendeklarasikan bagaimana aplikasi harus berjalan, dan sistem akan secara otomatis memastikan konfigurasi tersebut diterapkan.

3. **Menyediakan CLI (`kubectl`) untuk berinteraksi dengan API Server**  
   Dengan menggunakan `kubectl`, pengguna dapat menjalankan perintah untuk mengelola kluster, melihat status aplikasi, serta mengelola deployment.

4. **Rekonsiliasi antara keadaan saat ini dan keadaan yang diinginkan**  
   Kubernetes secara otomatis akan menyesuaikan keadaan sistem dengan konfigurasi yang telah dideklarasikan oleh pengguna.

5. **Menyediakan abstraksi layanan (Service) untuk membantu routing trafik**  
   Kubernetes memiliki mekanisme layanan (Service) yang memungkinkan aplikasi untuk tetap dapat diakses meskipun pod atau container di belakangnya berubah.

6. **Menyediakan antarmuka untuk integrasi jaringan, penyimpanan, dan ekstensi lainnya**  
   Kubernetes mendukung berbagai plugin yang memungkinkan integrasi dengan sistem penyimpanan (Storage), jaringan (Networking), serta berbagai fitur lainnya.

## Kubernetes: Sebuah **Container Orchestrator**

Berdasarkan fitur-fiturnya, Kubernetes mendefinisikan dirinya sebagai **"production-grade container orchestrator"**, atau **orchestrator container untuk lingkungan produksi**. Dalam istilah yang lebih sederhana, Kubernetes adalah sistem yang memungkinkan kita menjalankan dan mengelola container dalam skala besar di berbagai host.

## Kesimpulan

Meskipun Kubernetes memiliki cakupan yang luas, **esensi utama Kubernetes adalah mengelola workload berbasis container secara otomatis**. Dengan memahami fungsi-fungsi dasar ini, kita bisa mulai menjelajahi bagaimana Kubernetes dapat membantu dalam proses deployment aplikasi, otomatisasi skala besar, serta pengelolaan aplikasi dalam produksi.
